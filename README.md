# 朧の夢祀り ―Oboro no Yume-Matsuri―

昔ながらのドット絵で描かれた、約10分の短編アドベンチャーゲーム。

> 記憶をなくした少女は、夜の田舎町に迷い込む。
> 人のいない、灯だけがともる祭りの夜。
> 「幽世（かくりよ）」と名乗る男と歩く、朧月夜の物語。

※本作には虐待に関する描写が含まれます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要）。

ローカルサーバーで起動する場合：

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 操作方法

| 操作 | キーボード | タッチ |
|---|---|---|
| あるく | ←→ / A D | 画面の左はし・右はし |
| すすむ／決定 | Z / Enter / Space | 画面中央タップ |
| 選択肢 | ↑↓ で選び Z で決定 | 選択肢を直接タップ |
| 消音切替 | M | ― |

- 最初に「ほんとうの なまえ」を聞かれます。物語の最後まで覚えていてくれる人がいます。
- プレイ時間はおよそ10分です。

## 技術メモ

- HTML5 Canvas + Vanilla JS（依存ライブラリなし、ビルド不要）
- ドット絵はすべて文字列ピクセルマップによる手打ち
- BGM・効果音は WebAudio によるチップチューン風の動的生成
- フォントは [DotGothic16](https://fonts.google.com/specimen/DotGothic16)（オフライン時は等幅フォントにフォールバック）
